The First Web Server (CERN httpd)

August 6, 1991

Berners-Lee publicly an announces the World Wide Web project along with releasing the first website info.cern.ch . The website was hosted on Berners-Lee’s NeXT computer with the web server named CERN httpd

The First Web Server outside Europe

December 12, 1991

Stanford Linear Accelerator Laboratory launches the first website in the United States slac.stanford.edu with it being the first website to be linked to a database and the first webserver outside of Europe, beginning the "World" part of the World Wide Web.

CERN httpd goes to public domain

April 30, 1993

Berners-Lee and his team succeed in pressuring CERN to release the World Wide Web to the public domain allowing everyone to build and develop for the project leading to its success today.

NCSA HTTPd

1993

NCSA HTTPd was released in 1993 with its most impactful feature CGI (Common Gateway Interface) a standardize way for web servers to send request to other servers or programs enabling dynamic servers. The base code of NCSA HTTPd is still powering a large part of the World Wide Web to this day.

Apache

1995

The Apache HTTP Server was developed by a group of developers who volunteered to continue making patches to NCSA HTTPd. It became one of the most popular web servers today due to its flexibility and open-source nature.

Nginx

2004

Nginx was developed by Igor Sysoev in 2004 because of the C10k problem. It has since become a popular web server known for its high performance and low resource consumption.
