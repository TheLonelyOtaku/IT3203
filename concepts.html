HTTP/HTTPS

HTTP (Hypertext Transfer Protocol) is the protocol that is used for communication between client devices and web servers on the World Wide Web. HTTPS (HTTP Secure) is the secure version of HTTP where encryption is used to protect the data being transferred.

HTML

HTML(Hypertext Markup Language) is the standard coding language that web servers use to know how the different elements of the website (text, headings, images, and video) is laid out.HTML is compatible with all types of computer with internet access. This means any type of computer like a phone or laptop to devices to smart TVs or smart thermal stat can visit a website.

CSS

CSS (Cascading Style Sheets) is a coding language that is used to style the HTML elements of a website. CSS is used to change the color, size, and position of the elements on a website. CSS is also compatible with all types of computer with internet access.

Static/Dynamic Websites

A Static Web server is a web server that will send the same data on the server to the client like a HTML file, an image, or a PDF. All the server needs to do is read from storage and send.A Dynamic Web Server is a web server that generates the website when requested. It needs to search though a database for the required data and builds the website per user request like comments on a video or google search results. Modern web servers typically use both, a main page that likes the same to everyone for speed and an advertisement section that generated per user.

Web Server vs. Application Server

A Web Server is the server that handles all the HTTP requests and serving the static content to the client like text, images, and videos.An Application Server is the server that handles all the dynamic content like generating data from the database for the user and forwarding it to the web server. The Application server is usually not exposed to the web but instead is behind a web server.

Reverse Proxy

A reverse proxy is a server that is in front of a web server that handles external requests and directs them to the correct server. It is like a security guard that tells which door to go through.

CDN

A CDN is a network of server all over the world that is working together to deliver data to clients and spreading the load. If your located in the New York, you will get connected to the edge server in New York instead of the main server in Mexico.The advantages of CDN are lower latency- you physically closer to the server, faster downloads- less people competing for bandwidth, and redundancy-if one server goes down you connect to another server instead.
